# AI 私人本地化记忆管理

一套为 AI 助手（Claude Code）设计的本地记忆系统，让你的 AI 拥有长期记忆能力。

## 核心功能

- **四层记忆模型**：会话工作记忆 → 个人画像 → 经验洞察 → 表达风格
- **开箱即用**：零配置启动，自动检测知识库内容
- **全自动路由**：AI 自动判断信息属于哪一层级，写入正确位置
- **安全备份**：写入前自动备份，保留最近 10 个版本
- **代谢收敛**：自动归档过期信息，防止记忆膨胀
- **CRUD 完备**：支持记忆的创建、读取、更新、删除

## 记忆层级

| 层级 | 名称 | 作用 |
|------|------|------|
| L1 | 会话 | 当前焦点任务、活跃项目、下一步待办 |
| L2 | 个人画像 | 身份、角色、技术栈、人际关系 |
| L3 | 经验洞察 | 项目决策、生活反思、认知框架 |
| L4 | 表达风格 | 语气偏好、排版规范、句式习惯 |

## 快速开始

### 前置条件

- [Claude Code](https://claude.ai/claude-code) 已安装

### 安装

1. 将本仓库的 `SKILL.md` 放到你的 Claude Code 能访问到的路径
2. 首次使用 Claude Code 时，AI 会自动引导你设置知识库路径
3. 按照引导完成初始化即可

### 使用

| 指令 | 功能 |
|------|------|
| `状态` / `记忆状态` | 查看当前记忆系统状态 |
| `记一下` / `记住` / `保存` | 保存当前信息到记忆 |
| `学习一下我的风格` | 学习并记录你的表达风格 |
| `更新记忆` | 更新记忆并查看状态 |

## 设计哲学

记忆的本质是让 AI 能在对话中，对用户的私人信息执行 CRUD：

- **Create**：新信息被识别、分类、存入正确的位置
- **Read**：相关信息在需要时被精确唤醒
- **Update**：已有事实被更新，旧版本被安全备份
- **Delete**：过时信息被收敛归档，防止熵增
