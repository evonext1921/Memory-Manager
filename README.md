# Memory-Manager — 给 AI 装一个本地记忆

> 🌐 [memory.evonext.cn](https://memory.evonext.cn) — 项目介绍页

一个纯本地的 AI 记忆系统。不依赖向量数据库、不依赖云端 API、不需要任何外部服务。
纯 Markdown 目录 + 确定性路由，给你的 AI 开箱即用的私人上下文。

## 为什么要做这个？

每次新对话都要重新自我介绍一遍，它还是不知道你是谁、做什么的、说话什么风格。
之前聊过的方案、敲定的决策、总结的经验，下次对话全清零。——**你不烦吗？**

你要的不是一个每次都要重新调教的聊天窗口。
你要的是一个**越用越懂你**的 AI——记得你的背景、你的决策、你的风格，而且所有数据都在你自己硬盘上。

## 核心能力

| 层级 | 名称 | 作用 |
|------|------|------|
| L1 | 会话 | 当前焦点任务、活跃项目、下一步待办 |
| L2 | 个人画像 | 身份、角色、技术栈、人际关系等静态事实 |
| L3 | 经验洞察 | 项目决策、复盘总结、认知框架等动态经验 |
| L4 | 表达风格 | 语气偏好、排版规范、句式习惯等表达 DNA |

- **不用重复交代** — 它知道你的背景。新对话自动加载 L1+L2
- **决策不丢失** — 它记得你定过的事。项目决策自动路由到 L3
- **输出像你本人** — 不是 AI 腔。输出前自动校对 L4 风格
- **数据在你这** — 纯本地 Markdown，结构清晰，Obsidian 可直接编辑

## 快速开始

### 前置条件

- 一个支持导入自定义 Skill/Instructions 的 AI 客户端（如 [Claude Code](https://claude.ai/claude-code)、Codex 等）

### 安装

1. 将本仓库的 `SKILL.md` 放入你的 AI 客户端 skills 目录
2. 首次启动时 AI 会询问你的知识库路径（如 Obsidian Vault 路径），系统自动创建 `0 记忆系统/` 文件夹
3. 说 **"状态"** 查看记忆概览，说 **"记一下"** 保存信息

### 常用指令

| 你说 | 它做什么 |
|------|---------|
| `状态` / `记忆状态` | 显示当前记忆概览 |
| `记一下` / `记住` / `保存` | 自动识别内容归属 L2/L3，路由到对应文件 |
| `我是…` / `我在做…` | 保存个人画像 → L2 |
| `我决定…` / `我的结论是…` | 保存经验洞察 → L3 |
| `学一下我的风格` | 学习表达偏好 → L4 |

## 凭什么把记忆交给它？

- **写前自动备份** — L2/L3/L4 修改前自动备份，每个文件保留最近 10 个版本
- **代谢收敛** — 超过 5 条记录或 2000 字时自动提炼主干、归档旧记录
- **目录自愈** — 误删文件时 AI 静默重建，不打断对话
- **不脑补** — 只记你明确表达的内容，不作假、不推演

## 设计哲学

记忆的本质是让 AI 能在对话中，对用户的私人信息执行 CRUD：
**Create** → **Read** → **Update** → **Delete**。

不做向量检索 = 不会产生幻觉召回；不做云端同步 = 数据 100% 在你硬盘上；
不做自动语义理解 = 每次写入你都清楚记了什么。

适合需要 **"确知系统知道什么"** 的人。
